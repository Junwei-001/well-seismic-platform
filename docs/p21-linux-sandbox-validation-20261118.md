# P21 开发折：Linux 隔离环境增量验收（2026-11-18）

## 验收边界

师兄提供的非生产 Linux 沙箱包含慧眼完整参考源码及封存资源。本轮在独立运行目录安装本分支代码，未改动参考工作树、线上服务或任何封存输入。仅将 Volve P21 的五个已准备开发折载荷和可选断层轻量载荷安装到该运行目录；模型目录通过原有大小及 SHA-256 门禁。此处的 P21 是**已封存开发折的条件重建**，不是新工区预测或完整三维体积推理。

本次选用 fold 0。原生 P21 输出 `p21_query_points.npz` 含 `query_coordinate[2048,3]` 和 `prediction[2048]`；页面为这些查询点的交互 3D/2D 查看器。三维 SEG-Y/断层叠加属于可选增强，本次不把它记为验收完成。

## 测试和限制

慧眼 Harness/页面/DVC 的 48 项针对性测试中，47 项在 `full_runtime` 通过；剩余 1 项专门断言**接口模式**缺模型时返回 blocked，在其预期的 `interfaces_only` 模式单独通过。不同模式的结果分别记录，不写成同一模式下 48/48。

此次 Linux 环境真实运行的是一个典型业务案例。没有验证九模型、118 项载荷、未封存新工区、科学效果、生产部署或可选三维 SEG-Y 叠加。完整演示视频、两页 PPT 和 PR 描述应以最终浏览器验收画面为准，并保留上述适用范围。
