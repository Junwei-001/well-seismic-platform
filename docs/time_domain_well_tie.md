# 时间域井震标定方案

## 适用边界

本系统中的地震纵轴是双程时间（TWT，毫秒），测井曲线纵轴是测量井深（MD）。两者不能直接拼接。
每个样本必须先明确完成两类独立对齐：

1. 水平对齐：井轨迹 `X/Y` 对应到同一三维地震体的 Inline、Crossline 和地震道；
2. 垂向标定：`MD/TVD/TVDSS` 经可追溯变换得到 `TWT`。

没有时深表时，系统可以生成声波积分和合成地震的候选标定，但不会把候选结果冒充人工井震标定。

## 开源方案调研与取舍

| 项目 | 可复用思想 | 许可证与采用方式 |
|---|---|---|
| [SEG tutorials-2014](https://github.com/seg/tutorials-2014) | 慢度积分得到时深关系、阻抗差分得到反射系数、子波卷积得到合成记录 | Apache-2.0；作为物理流程依据 |
| [Bruges](https://github.com/agilescientific/bruges) | Ricker 子波、反射系数等地球物理基础算子 | Apache-2.0；当前未增加运行时依赖，采用等价的原生 NumPy 实现 |
| [PyTie](https://github.com/raquelsilva/pytie) | 完整井震标定教学流程、子波与时移分析 | GitHub 仓库为 AGPL-3.0；不复制、不内嵌其代码 |
| [segyio](https://github.com/equinor/segyio) | SEG-Y 索引与按需读取 | LGPL-3.0；当前系统已有按需读取器，不为本次标定额外引入 |
| [CWP constrained dynamic warping](https://cwp.mines.edu/wp-content/uploads/sites/112/2018/08/CWP725-min.pdf) | 受约束非线性时间校正 | 作为后续候选；当前不启用，避免弱先验下产生看似高相关但地质上错误的拉伸/压缩 |

本次实现没有复制第三方源代码，只按公开的标准地球物理方程编写 NumPy 算法，因此没有新增强制依赖。

## 已实现工作流

```text
井位/轨迹 + LAS
  ├─ 水平：选择距井最近的三维地震体
  │        → KDTree 检索邻近 9 道
  │        → 反距离加权合成井旁参考道
  └─ 垂向：实测时深表优先
           └─ 无时深表：VP/DT → TVD 慢度积分 → 初始 TWT
                        RHOB/PIMP/Gardner → 密度
                        速度×密度 → 阻抗 → 反射系数
                        Ricker 子波卷积 → 合成地震
                        与井旁参考道做有界静移和极性检验
                                  ↓
                     固定 32 样点地震窗口 + 质量状态 + 来源记录
```

### 1. 水平邻域

- `survey_selection.mode: nearest_3d`：二维测线不参与三维井震样本；每口井在可用三维体中选择最近者。
- `neighbor_traces: 9`：井旁参考地震不是单道，而是邻近道的反距离加权组合，可降低单道噪声和定位微小偏差的影响。
- 每个最终样本仍记录最近道、全部邻域道索引及其权重。

### 2. 时深先验

优先级由 `vertical.preferred` 控制：

1. `provided_time_depth`：保存原表的深度域（MD/TVD/TVDSS）、深度单位、时间单位和来源；查询时不再把 MD 表错误套到 TVD。
2. `sonic_integrated`：在 TVD 域积分声波速度。速度来源按“有效覆盖率 × 来源质量”选择 `VP`、`DT` 或 `PIMP/RHOB`。
3. `constant_velocity`：仅在显式启用时生成低置信度初始关系。
4. `none`：只保留水平匹配。

声波积分必须显式记录替代速度、参考深度、地震时间基准及最大允许井深缺口。配置未确认基准时会降低置信度。

### 3. 合成地震与校正

- 密度优先使用 `RHOB`，其次由 `PIMP/VP` 计算，缺失段才使用 Gardner 关系估计。
- 反射系数采用法向入射声阻抗差分，默认卷积 30 Hz 零相位 Ricker 子波。
- 只允许配置范围内的整体静态时移，并检测极性；当前不做无约束 stretch/squeeze。
- 相关系数低于阈值时不接受静移，只保留声波积分初始关系。

### 4. 状态与放行门禁

| 状态 | 含义 | 默认训练资格 |
|---|---|---|
| `provided_tie` | 用户提供的实测时深关系 | 垂向可用，仍需通过水平与坐标门禁 |
| `estimated_tie` | 合成记录相关达到候选阈值 | 否 |
| `vertical_initial` | 只有声波积分/常速初始关系，或相关未通过 | 否 |
| `horizontal_only` | 只有平面位置匹配 | 否 |

样本成为 `training_eligible=true` 必须同时满足：

- 固定长度地震窗口完整且为有限值；
- 垂向标定本身被允许用于训练；
- 水平和垂向置信度分别达到阈值；
- `matching.coordinate_reference.verified=true`，即已经人工核对井位与 SEG-Y 的 CRS、长度单位和坐标缩放。

默认配置将坐标参考设为未核验。系统仍生成可视化和候选窗口，但多模态训练门禁保持关闭。

## 主要配置

配置文件为 `configs/matching.yaml`：

- `coordinate_reference`：CRS 与水平单位人工核验状态；
- `survey_selection`：三维地震体选择规则或显式资产过滤；
- `neighbor_traces`：井旁参考道邻域规模；
- `vertical.sonic`：速度范围、缺口、替代速度、子波、最大静移和相关阈值；
- `seismic_window_samples`：下游样本的精确地震窗口长度。

## 当前仍需人工或后续实现的部分

- 自动识别 EPSG、井位 CRS 与 SEG-Y CRS，并执行可审计重投影；
- 从井旁地震估计子波振幅谱、相位与时变特性；
- 在人工复核界面显示合成记录、井旁地震、相关曲线和标定控制点；
- 对已批准候选建立版本化审批记录，而不是直接修改全局配置；
- 经盲井验证后再考虑受约束动态时移，且必须保留原始与校正后的时深曲线及不确定度。

## 当前样例数据验证（2026-07-23）

对项目内 `比赛输入示例_自动识别` 全量运行：109 个资产、11 个 SEG-Y、20 个井实体，读取错误为 0；
共生成 2,909 条候选样本，2,522 条具有完整时间窗，所有窗口长度均严格为 32。样本垂向状态为
`provided_tie=2152`、`vertical_initial=485`、`estimated_tie=272`。

带 `verticalDepth` 表头的 4 组时深关系已按 TVD 注册；另有 1 个无表头、无井名且未说明深度域的
候选表被隔离并进入质量警告，没有再按 MD 默认猜测。

自动静移候选相关性较低，例如 Q109 为 0.301（26 ms），Q124 为 0.202（97 ms），均未放行训练。
当前配置尚未确认井震 CRS 与单位，因此可训练样本为 0，`can_train_multimodal=false`；这是质量门禁的
预期结果，不代表候选窗口生成失败。
