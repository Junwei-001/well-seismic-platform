# 通用预处理与小模型输入协调方案

## 目标

平台不产出一个被所有模型强制共用的“万能张量”。平台只维护可信、可追溯的标准数据层；每个小模型通过自己的输入适配器，把标准数据转换为该模型真正需要的张量。

## 五层处理结构

1. **原始资产层**
   - 保留 SEG-Y、LAS、井位和井轨迹原文件及来源。
   - 不覆盖、不复制大型原始数据。
2. **标准数据层**
   - SEG-Y：端序、采样格式、Inline/Crossline、XY、时间轴和规则网格。
   - LAS：标准曲线名、单位、深度轴、有效掩码。
   - 井数据：井实体、井口、轨迹和置信度。
3. **用途视图层**
   - 可视化视图：模型无关的三维稀疏体、二维测线、切片和井轨迹叠加；CIGVis只消费该视图，不改变标准数据。
   - 井震样本视图：井旁道、时深关系和多模态样本。
   - 模型视图：由模型输入适配器按需生成，不要求所有任务先构建井震样本。
4. **模型输入适配层**
   - 每个模型注册 `ModelInputAdapter`。
   - 适配器声明来源格式、轴序、通道、dtype、最小尺寸、patch、归一化、缺失值和是否需要测井。
   - FaultSeg：`[Z, Inline, Crossline] → [N,1,Z,Inline,Crossline]`，逐 patch z-score。
5. **任务推理与输出层**
   - 每个任务包含多个可替换模型。
   - 每个模型同时注册输入适配器和推理运行器。
   - 输出概率、掩码、坐标范围、阈值、权重版本及源数据任务 ID。

## 放行规则

模型运行前必须同时满足：

- 源资产可读；
- 几何或深度轴满足任务要求；
- 数据尺寸达到模型最小输入尺寸；
- 已注册对应输入适配器；
- 已注册对应推理运行器；
- 适配产物通过 shape、dtype、有限值和轴序校验。

可视化预览不是模型推理的强制输入，但它是数据网格正确性的独立诊断视图。预览失败时必须显示具体原因，不能把失败笼统归因于“没有三维数据”。

系统预览三维轴序固定为`[Z, Inline, Crossline]`。进入CIGVis时仅由可视化适配器转为`[Inline, Crossline, Z]`；模型适配器继续按各自契约读取标准数据，二者不能互相复用隐式转置结果。

## 当前实现状态与边界

上述五层是目标架构；当前已经落地的是“原始资产只读 + 基础标准化 + 用途适配器”，标准数据层
尚未物化成可被所有下游任务直接复用的持久化数据块：样本构建和 FaultSeg 仍会按任务重新打开
原始路径，`source_task_id` 主要承担血缘和可视化关联。

- LAS 已执行空值哨兵转 `NaN`、深度单位转米、深度排序、重复深度聚合、曲线标准名/单位换算、
  物理硬范围置空和有效掩码；尚未执行统计离群、尖峰检测、重采样、插值、去噪或平滑。
- 通用 SEG-Y 层已执行格式/端序/道头/坐标缩放/Inline-Crossline/时间轴解析和按需读取；尚未执行
  死道坏道、异常振幅、去趋势、带通、AGC、相位极性、时间重采样等正式地震处理。
- FaultSeg 的规则网格重建和逐 patch z-score 是模型专属输入适配，不等于共享地震预处理。
- 水平井震对齐先选择距井最近的三维地震体，再用 XY 邻近 9 道反距离加权构建井旁参考道；系统
  当前没有 CRS 自动识别和重投影，因此 CRS 与长度单位必须显式核验。未核验时可生成候选，但不能
  放行多模态训练。
- 垂向优先使用带 MD/TVD/TVDSS 域和单位来源的实测时深表；缺少表时可用 DT/VP 在 TVD 域积分，
  结合 RHOB/PIMP/Gardner、反射系数和 Ricker 子波生成合成地震，并做有界静态校正。自动结果默认
  只是候选，不直接进入训练。完整边界见 [时间域井震标定方案](time_domain_well_tie.md)。

## 任务与模型关系

- 断层分割：FaultSeg（当前可运行），后续可增加其他 2D/3D 断层模型。
- 层位追踪：独立任务页面，模型应输出层位面或层位概率。
- 沉积相预测：可接地震单模态或井震多模态模型。
- 裂缝识别、有利储层、有利目标：分别维护自己的输入和输出契约。

任务决定业务语义和输出类型；模型决定输入张量与推理实现。两者不能混为同一层。

## 任务血缘

- 数据准备任务 ID 永远指向标准数据和可视化预览。
- 推理任务使用独立 ID，并记录 `source_task_id`。
- 启动推理不能覆盖当前数据任务 ID。
- 可视化始终读取数据任务；从推理任务进入可视化时，服务端沿 `source_task_id` 返回源数据预览。

## 新模型接入步骤

1. 注册 `ModelSpec`，声明所属预测任务。
2. 实现并注册 `ModelInputAdapter`。
3. 实现并注册 `PredictionRunner`。
4. 增加兼容性与真实样本测试。
5. 前端自动在对应任务页面的模型下拉框中展示该模型。
